# X platform rules

Distilled from the `twitter-x-posts` skill (kostja94/marketing-skills). Only
the rules that shape draft text live here. The skill's reach and algorithm
figures are unsourced, so they steer no rule on their own.

## Hook

- Tweet 1's first line carries the payoff in about 50 characters. The reader decides there whether to expand.
- Open with a question, a number, or a concrete fact. Never announce that a thread follows.

## Body

- Each tweet stands alone. A reader who lands on tweet 3 from a quote should still get one complete idea.
- Short beats full: a tweet of 70 to 130 characters reads better than one packed to the limit.
- Do not number tweets. Mastisk appends "n/N" after drafting.

## Ending

- End on an open question only when the thread leaves a real unresolved test the reader could answer from their own work.
- Otherwise end on the concrete next thought or caveat.
- Never end with generic engagement bait: "thoughts?", "what do you think?", "RT if you agree", "follow for more".

## Links and tags

- No URLs in tweet text. X down-ranks posts with external links. If a link matters, name it in `warnings` so the user can post it as the first reply.
- Hashtags: none by default, at most one, and only for a named event or community tag.
